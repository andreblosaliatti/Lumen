# LUMEN — Assets para Web

Arquivos independentes, prontos para importar no site.

## Logos
- `logo-lumen-principal.webp`: marca sem a assinatura inferior (fundo transparente aproximado).
- `logo-lumen-completo.webp`: marca e assinatura (fundo transparente aproximado).

**Atenção:** os WebP foram extraídos da imagem JPEG enviada; não são arquivos vetoriais originais da marca. Transparência reconstruída a partir de fundo preto; para uso profissional definitivo, prefira receber o logo fonte em SVG/AI.

## Recomendações
Use SVGs como imagens / backgrounds e WebP com `width` e `height` declarados, `loading="lazy"` em elementos fora da primeira dobra. SVG pode escalar sem perder nitidez. Para responsividade, prefira desenhar bordas de cartões e botões via CSS (gradiente), usando os SVGs como referência visual, porque uma imagem esticada pode deformar o raio das bordas. SVGs vetoriais têm fundo transparente exceto `fundo-aurora.svg`.
